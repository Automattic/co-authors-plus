# Querying posts by author or co-author

Co-Authors Plus makes WordPress author queries include posts where a user is a co-author. Use the standard `WP_Query` author arguments.

## Query posts for one WordPress user

Pass the user's WordPress ID to `author`:

```php
$user_id = 123;

$query = new WP_Query(
	array(
		'post_type'      => 'post',
		'posts_per_page' => 20,
		'author'         => $user_id,
	)
);
```

This returns posts where the user is either the primary WordPress author or a Co-Authors Plus co-author.

The query filters are active when Co-Authors Plus is loaded. They update the SQL generated by `WP_Query` to include matching terms from the `author` taxonomy.

## Query posts for multiple users

Use `author__in` with an array of WordPress user IDs:

```php
$query = new WP_Query(
	array(
		'post_type'  => 'post',
		'author__in' => array( 123, 456 ),
	)
);
```

The older comma-separated `author` form is also supported:

```php
$query = new WP_Query(
	array(
		'post_type' => 'post',
		'author'    => '123,456',
	)
);
```

Use `author__in` for new code because it makes the multiple-author query explicit.

## Query by author slug

Use `author_name` with a user's `user_nicename`:

```php
$query = new WP_Query(
	array(
		'post_type'   => 'post',
		'author_name' => 'jane-doe',
	)
);
```

## Elementor custom queries

For an Elementor Posts or Loop Grid widget, set a Query ID and add a callback to Elementor's custom query hook. The callback receives the `WP_Query` object:

```php
function my_coauthor_query( $query ) {
	$query->set( 'author__in', array( 123 ) );
}
add_action( 'elementor/query/my_coauthor_query', 'my_coauthor_query' );
```

Use `author__in` in this callback so Co-Authors Plus recognizes the programmatic author query and includes co-author taxonomy matches. This uses Elementor's custom query integration and Co-Authors Plus' normal `WP_Query` behavior. Elementor configuration and available query controls depend on the Elementor version and widget. Co-Authors Plus does not add an Elementor-specific widget control.

## Guest authors and supported post types

`author` and `author__in` expect WordPress user IDs. Guest authors are Co-Authors Plus taxonomy terms and do not always have a matching WordPress user ID. Query a guest author with `author_name` and the guest-author slug where supported, or use a taxonomy query with the `author` taxonomy term.

The post type must be supported by Co-Authors Plus and registered with the `author` taxonomy. Queries for unsupported post types keep normal WordPress `post_author` behavior.

## Changing query behavior

By default, Co-Authors Plus matches both the `post_author` column and co-author taxonomy terms. Use `coauthors_plus_should_query_post_author` when the site should keep taxonomy matching but stop including the primary `post_author` condition:

```php
add_filter( 'coauthors_plus_should_query_post_author', '__return_false' );
```

Use `coauthors_plus_is_author_query` to opt a specific query out of the Co-Authors Plus SQL rewrite entirely. The query then uses normal WordPress primary-author behavior:

```php
add_filter(
	'coauthors_plus_is_author_query',
	function ( $is_author_query, $query ) {
		return false;
	},
	10,
	2
);
```
